선택한 목록의 비밀번호와 Bypass Code가 포함됩니다.

검색하고, Enter.

  1. 테넌시, 아이디, 비밀번호, Bypass Code를 등록하세요.
  2. 단축키로 열고 테넌시 또는 고객사명을 검색하세요.
  3. Enter를 누르면 OCI 화면 입력과 인증 방식 선택이 이어집니다.

시크릿 창에서 실행하면 로그인도 같은 시크릿 창에서 진행합니다. 처음에는 확장 관리 → 세부정보 → 시크릿 모드에서 허용을 켜세요. 저장된 계정과 테마는 일반 창과 공유합니다.

기본 단축키: Ctrl + Shift + Space
팝업에서 계정 추가: Alt + N
변경: Chrome·Brave는 chrome://extensions/shortcuts
Prisma는 prisma://extensions/의 단축키 메뉴

OCI의 최초 접근 권한을 허용해 주세요. 별도의 기업 SSO, CAPTCHA, 화면 구조 변경은 직접 확인이 필요할 수 있습니다. 기존 세션이 있으면 테넌시·아이디·도메인이 모두 일치할 때 선택하고, 없으면 새 로그인을 시작합니다.

개인 인증 정보는 확장프로그램 전용 로컬 저장소에 저장됩니다. 잠금·암호화 금고 기능은 제공하지 않습니다. 서버 전송이나 Chrome 동기화는 사용하지 않습니다.
