OCI Companion1.2.3 설치 도우미

빨간 박스를 따라 설정하세요.

선택할 확장 폴더

1확장 관리 → 개발자 모드 → 압축해제된 확장 프로그램 로드

2폴더 선택 창에 경로 붙여넣기

위에서 복사한 경로를 주소창에 붙여넣으세요. 예시 화면은 공통 경로 표기입니다.

1기존 카드에서 새로고침

설치했던 같은 브라우저와 같은 프로필에서 진행하세요. 기존 카드를 삭제하거나 새로 추가하지 마세요.

3세부정보 열기

4시크릿 모드에서 허용 켜기

이제 시크릿 창에서도 사용할 수 있습니다.

Ctrl+Shift+N새 시크릿 창
Ctrl+Shift+SpaceOCI Companion 열기

단축키가 안 되면 브라우저의 확장 프로그램 메뉴에서 OCI Companion을 선택하세요.

공식 안내와 촬영 정보

계정이 없는 Chromium 145 테스트 프로필의 실제 확장 관리 화면입니다. 폴더 선택은 Windows 화면의 주소창과 버튼만 표시했습니다. 빨간 박스는 SVG로 덧붙였습니다.
