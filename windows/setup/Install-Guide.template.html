OOCI Companion · Windows 설치 도우미

확장 파일 준비 완료.
Chrome에서 마지막 3단계만 진행하세요.

함께 열린 Chrome의 확장 프로그램 탭으로 이동하세요.
탭이 열리지 않았다면 주소창에 chrome://extensions를 입력하세요.

  1. 오른쪽 위 개발자 모드를 켭니다.이미 켜져 있으면 그대로 두세요.
  2. 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  3. 폴더 선택 창에서 아래 경로를 선택합니다.Ctrl+L → Ctrl+V → Enter → 폴더 선택.

등록 후 퍼즐 아이콘에서 OCI Companion을 고정하세요.
Ctrl+Shift+Space로 열고, 계정을 추가한 뒤 테넌시를 검색하세요.

설치 폴더는 계속 사용하는 위치이므로 삭제하거나 옮기지 마세요. 다운로드한 설치 CMD 파일은 등록 후 삭제해도 됩니다.
기존 확장을 다른 폴더에서 사용 중이었다면 먼저 설정 → 데이터 → JSON 내보내기로 백업하고, 새 확장에서 가져오세요. 기존 확장과 계정은 설치 도우미가 삭제하지 않습니다.
팀 JSON 전체 경로를 쓰는 Windows 보조 프로그램은 선택 기능입니다. 기본 설치에서 자동 등록하지 않습니다.
이 도우미는 파일 배치와 화면 열기를 처리합니다. Chrome의 등록 버튼은 사용자가 직접 누릅니다.
