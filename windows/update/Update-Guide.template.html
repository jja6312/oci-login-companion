OOCI Companion · 1.1.1 업데이트

기존 계정을 유지한 채 업데이트했습니다.

확장 프로그램을 사용하던 같은 브라우저·같은 프로필에서 마무리하세요.

  1. 확장 관리 화면을 엽니다.Chrome: chrome://extensions · Brave: brave://extensions
  2. 기존 OCI Login Companion 카드의 새로고침 ⟳을 누릅니다.확장을 삭제하거나 새 항목으로 추가하지 마세요.
  3. 확장 버전 1.1.1을 확인하고 테넌시를 다시 검색합니다.사이트 접근 허용 창이 나오면 OCI 로그인 주소를 허용하세요.

기존 확장 폴더 경로를 유지하므로 브라우저의 계정·테마 설정을 그대로 사용합니다. 이전 확장 파일은 같은 설치 폴더의 extension-backup-1.1.0-*에 보관했습니다.
OCI 세션 선택 화면에서는 테넌시·아이디·도메인이 모두 일치하는 세션만 선택합니다. 없으면 다른 계정 로그인으로 이어집니다.
업데이트 후에는 이전에 멈춘 로그인 탭 대신 확장 검색창에서 새로 실행하세요.
