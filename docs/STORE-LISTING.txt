Chrome Web Store 제출 준비 자료 · 1.3.0 (게시되지 않음)
이름: OCI Login Companion
설명: 테넌시를 검색하고 Enter. 아이디·비밀번호·Bypass Code까지 OCI 전용 자동 로그인.

개인 확장 전용 로컬 저장소와 공유 팀 JSON을 지원합니다. 개인/팀을 선택해 가져오고 내보내며, 편집 권한이 있는 사용자는 연결된 팀 파일을 갱신할 수 있습니다. 단축키로 열어 테넌시를 검색하고 Enter를 누르면 OCI 테넌시·Identity Domain·아이디/비밀번호·다른 인증 방식·Bypass Code·콘솔 이동 순서로 처리합니다. 다크/라이트/시스템 밝기와 사용자 지정 테마색을 제공합니다. 자체 서버·분석 수집·Chrome 계정 동기화는 없습니다. 외부 SSO/CAPTCHA는 수동 처리가 필요할 수 있습니다. 동일 테넌시·아이디·도메인 세션은 자동 선택하고 없으면 새 로그인합니다. 별도 암호화·잠금 금고는 아닙니다. Oracle/Bitwarden/Proton이 제작하거나 보증하는 제품이 아닙니다.

단일 목적: 사용자가 선택한 OCI 계정 로그인 입력 자동화.
권한 근거: storage(설정/계정/실행), scripting(OCI 자동입력), activeTab(현재 탭 입력만), alarms(작업 만료), webNavigation(작업 탭의 OCI 인증 이동과 정확한 문서 확인). 선택적 Oracle host 권한은 사용자가 로그인 실행할 때 요청하며 실제 값은 확인된 작업 문서에만 제공합니다. 선택적 nativeMessaging은 Windows 파일 전체 경로를 사용할 때 한 파일만 읽기 위해 요청합니다. 상세 범위는 PRIVACY.txt.
원격 코드 없음. 설정은 JSON 데이터와 제한된 CSS 선택자이며 실행 코드를 받지 않음.

게시 전 운영자 준비: 스토어 개발자 계정, 문의 연락처/운영 주체, 공개 개인정보 URL, 데이터 처리 공개 최종 검토, 실제 OCI/Windows 실기 검증, 게시 범위 선택. 이 패키지는 스토어 게시나 사용자 PC 설치 완료를 의미하지 않습니다.
