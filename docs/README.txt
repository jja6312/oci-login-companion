OCI Companion 1.3.3

처음 실행
로컬 저장소 / 팀 공유 파일 중 하나를 선택합니다.
로컬 저장소는 파일 없이 바로 시작합니다.
팀 공유 파일은 새 파일 만들기 / 기존 파일 선택 중 하나를 눌러 바로 연결합니다.
파일은 기본으로 편집 가능하며 별도 편집 허용 체크나 저장 위치 적용이 필요 없습니다.
파일 선택 취소·잘못된 파일은 같은 단계에서 다시 선택할 수 있습니다.
이후 다시 열면 선택한 목록을 바로 표시하고, 기존 사용자에게 선택 화면을 다시 띄우지 않습니다.
이후 저장 위치 변경은 설정 → 저장 위치에서 가능합니다.

업데이트
기존 설치는 GitHub의 최신 Install.cmd를 실행하고, 같은 브라우저/프로필 확장 관리에서 기존 OCI Companion 카드의 새로고침을 누릅니다.
확장을 삭제 후 재등록하지 마세요. 기존 계정·테마와 확장 ID는 같은 경로에서 유지합니다.
브라우저는 파일 선택 기능만 사용하며 별도 파일 보조 프로그램 설치가 필요 없습니다.

Brave 최초 설정
처음 팀 파일 연결 화면 또는 설정 → 저장 위치에서 ‘Brave 설정 열기’를 누릅니다.
File System Access API를 Enabled로 바꾸고 Relaunch를 누릅니다.
주소를 직접 여는 경우 brave://flags/#file-system-access-api 입니다.
확장을 다시 열어 OneDrive의 팀 JSON 파일을 선택합니다.
선택한 파일은 기본으로 편집 가능하며, 브라우저의 쓰기 승인은 필요합니다.
Chrome에서 파일 선택 기능이 이미 켜져 있으면 추가 설정이 나타나지 않습니다.
확장이 이 브라우저 설정을 자동 변경하지 않습니다.

사용
Ctrl+Shift+Space → 테넌시/고객사명 검색 → Enter.
Alt+N은 확장 화면에 포커스했을 때 계정 추가입니다.
별칭, 아이디, 비밀번호, 관리자 발급 Bypass Code를 계정마다 저장합니다.
일괄 등록은 Excel의 각 열을 테넌시/고객사/도메인/아이디/암호/코드에 붙여 넣고 행 수와 미리보기를 확인합니다.
화면 상단 원형 팔레트로 테마색을 바꿉니다.
시크릿 창 사용은 확장 관리의 시크릿 허용을 직접 켜야 하며, 시작한 창과 같은 모드에서 로그인합니다.

개인/팀
개인 목록은 현재 브라우저에 저장합니다.
팀은 각자의 PC에 동기화된 동일 OneDrive JSON 파일을 파일 선택으로 연결합니다.
파일을 열 때와 로그인 시작 때 다시 읽습니다. 읽기 실패 시 오래된 암호나 개인 목록으로 대신 로그인하지 않습니다.
브라우저 쓰기 권한이 있으면 편집/추가/삭제/가져오기/일괄 등록을 그 파일에 저장합니다.
다른 팀원의 변경은 각 PC의 OneDrive 동기화가 끝난 뒤 반영됩니다. 로컬 저장을 클라우드 완료로 표시하지 않습니다.
개인/팀 내보내기 및 가져오기는 데이터 탭에서 각각 대상을 선택합니다. 내보내기는 암호와 코드를 포함합니다.
이전 전체 경로 연결은 같은 JSON을 파일 선택으로 재연결하세요. 개인 목록과 기존 picker 연결은 유지합니다.

배포/검증
스토어 게시 없이 압축해제한 extension 폴더를 로드합니다. 기존 설치 업데이트는 같은 경로에서 진행합니다.
Install.cmd는 신규 설치와 기존 관리형 설치 업데이트를 함께 처리합니다. 설치/업데이트는 Windows 파일 추출과 기존 확장 파일 갱신용이며 파일 접근용 상주 프로그램이나 서비스가 아닙니다.
검증 범위는 validation-1.3.3.json을 참고하세요.
실제 사용자 Windows/OneDrive 클라우드와 고객 OCI 인증은 이 배포의 Linux 검증과 구분합니다.

파일 접근 복구
팝업을 닫은 뒤 파일 권한이 만료되면 메인 화면의 팀 파일 열기 또는 Enter로 복구합니다.
파일을 다시 선택하거나 저장 위치 적용을 반복할 필요가 없습니다.
브라우저 승인 창에 방문할 때마다 허용이 있으면 선택하세요. 영구 허용된 권한은 재시작 후에도 자동 사용합니다.
일회성 허용/차단/수동 권한 초기화 뒤에는 브라우저 재승인이 필요할 수 있습니다. 확장이 이를 자동 승인하지 않습니다.
