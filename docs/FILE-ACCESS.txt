OCI Companion1.3.5 — 팀 파일 열기와 검색

메인 화면
팀 파일 열기에 포커스된 상태에서 Enter를 누릅니다.
브라우저의 접근 승인을 허용하면 현재 파일을 다시 읽고 상단 테넌시 검색창에 포커스를 옮깁니다.
바로 테넌시 또는 고객사명을 입력하고 Enter로 로그인할 수 있습니다.
접근이 거절되면 파일 연결을 유지하고 팀 파일 열기에서 다시 시도할 수 있습니다.

설정 → 저장 위치
팀 파일을 선택하거나 기존 연결을 그대로 둡니다.
파일 접근 허용 및 저장 위치 적용을 한 번 누릅니다.
브라우저의 파일 쓰기 승인을 허용하면 선택한 파일을 검증하고 저장 위치를 적용합니다.
성공하면 설정을 닫고 검색창으로 포커스를 옮깁니다. 접근 다시 허용 버튼은 제거했습니다.
허용하지 않거나 파일이 잘못되면 기존 저장 위치와 연결을 유지합니다.
개인 저장소는 저장 위치 적용으로 전환하며 파일 접근 승인을 요청하지 않습니다.

브라우저 최초/영구 허용 승인과 조직 정책은 사용자가 직접 확인해야 합니다.
설치기는 브라우저 보안 설정이나 조직 정책을 변경하지 않습니다.
기존 계정·테마·연결을 유지하며, 금고 암호화/시작 잠금 해제 기능은 아직 미구현입니다.
