OCI Companion 1.3.0 — 개인 목록과 팀 파일

팀 공유 시작
1. 팀이 함께 사용하는 OneDrive 폴더에 JSON 파일을 준비합니다.
   확장 설정 → 저장 위치 → 팀 파일 → 새 팀 파일을 누르면 빈 파일을 만들 수 있습니다.
   이미 있는 파일은 파일 선택으로 연결합니다. 기존 파일은 새 파일 만들기로 덮어쓰지 않습니다.
2. 계정을 추가하거나 암호를 변경할 사람은 ‘팀 파일 편집 허용’을 켜고 브라우저의 쓰기 권한을 허용합니다.
   읽기 전용 사용자도 파일 선택과 저장 위치 적용은 필요합니다.
3. 저장 위치 적용을 누릅니다. 팀원도 각자의 PC에 동기화된 같은 OneDrive JSON을 선택합니다.
   파일 연결은 브라우저에 보관되고, 팀 계정은 개인 목록으로 자동 복사되지 않습니다.

목록 내보내기/가져오기
설정 → 데이터에서 가져올 위치와 내보낼 위치를 각각 개인 저장소 또는 연결된 팀 파일로 선택합니다.
내보내기는 해당 위치를 새로 읽어 JSON으로 저장합니다. 비밀번호와 Bypass Code가 포함됩니다.
가져오기는 기존 계정을 보존하며 합칩니다. 같은 ID의 값을 바꾸려면 ‘같은 ID의 계정 갱신 허용’을 켭니다.
팀 대상 가져오기와 편집·추가·삭제·엑셀 일괄 등록은 연결된 팀 파일 자체에 저장됩니다.
팀 파일 쓰기 권한이 없으면 가져올 위치를 개인 저장소로 선택해 개인 목록에만 가져올 수 있습니다.
목록 형식은 기존 schemaVersion:1과 같고, 앞자리0/공백을 포함한 암호와 코드를 유지합니다.

변경이 반영되는 시점
팝업을 열 때, 관리 화면에 다시 포커스할 때, 표시 중인 팀 목록을 주기적으로 갱신할 때 파일을 읽습니다.
로그인을 시작할 때도 worker가 파일을 다시 읽어 해당 시점의 아이디·암호·Bypass Code를 사용합니다.
진행 중인 한 번의 로그인은 일관된 값 묶음을 사용합니다. 변경은 다음 로그인부터 적용됩니다.
OneDrive 앱이 업로드/다른 PC의 다운로드를 완료한 뒤 그 PC에서 새 값을 사용할 수 있습니다.
확장이 OneDrive 클라우드 전송 완료를 확인하는 기능은 없습니다. 동기화 일시정지나 오프라인 상태는 자동 해제하지 않습니다.
같은 파일명으로 교체된 파일은 다시 읽으며, 브라우저가 기존 파일 연결을 잃으면 파일 선택으로 재연결합니다.

동시 편집과 오류
편집/가져오기 준비 뒤 로컬 파일이 바뀌면 이전 내용으로 덮어쓰지 않고 중지합니다.
가져오기는 ‘최신 목록 확인’ 후 다시 시도하고, 계정 편집은 입력을 확인한 뒤 닫고 새로 편집합니다.
파일을 읽지 못하거나 JSON이 잘못되면 이전 암호나 개인 목록으로 대신 로그인하지 않습니다.
브라우저 내부 쓰기를 직렬화하고, Native helper는 같은 PC의 쓰기를 잠근 뒤 기존 해시를 비교합니다.
이 검사는 여러 PC의 동시 오프라인 수정을 잠그는 분산 잠금이 아닙니다. OneDrive가 충돌 사본을 만들었다면 원본/버전 기록을 확인하세요.

Windows 전체 경로 연결 (선택 사항)
파일 선택 방식은 보조 프로그램이 필요 없습니다.
전체 경로 방식은 Windows 보조 프로그램을 설치하고, 허용된 JSON 전체 경로를 입력한 뒤 적용합니다.
기본 Install.cmd는 읽기 전용입니다. 팀 편집에는 Install-Team-Editor.cmd를 사용하거나 Install.ps1 -AllowWrite로 설치합니다.
Native helper는 설치 때 정한 확장 ID와 파일 경로 한 개만 허용합니다. 다른 경로를 사용하려면 helper 설정을 다시 설치합니다.
기존 읽기 전용 helper는 계속 읽을 수 있습니다. 1.3.0 확장 업데이트만으로 쓰기 허용이나 helper 설치를 자동 변경하지 않습니다.
브라우저 정책·실행정책·서비스·OneDrive 설정은 변경하지 않습니다.

검증 범위
독립 Linux Chromium 프로필 두 개와 실제 PS7 native stdio/file API를 사용해 같은 가상 팀 파일을 편집·다시 읽었습니다.
실제 OPFS 파일 핸들에서도 저장·해시 충돌·재연결/생성 UI를 검사했습니다. OCI 네트워크/실제 고객 인증은 사용하지 않았습니다.
실제 OneDrive 계정의 클라우드 전송, Windows CMD/PS5.1/레지스트리, Windows 파일 선택·권한창은 미검증입니다.
